Is the chest X-ray model reading the lungs?

A popular Kaggle set sorts 7,135 chest X-rays into COVID-19, normal, pneumonia and tuberculosis, and models trained on it report about 98%. Here the same kind of model runs in your browser, at full size and pruned 42 times smaller. Press Hide the lungs to see what a model trained only on the edges of the image still gets right.

Loading models…

Samples are test images from the pediatric pneumonia set (Kermany et al., CC BY 4.0) that the models never trained on. Your own image stays on your device. Research and education only, not for diagnosis.

What the 92% is made of

Each class comes from a different collection. Normal and pneumonia images are children aged one to five from one hospital in Guangzhou; the tuberculosis images are all 512 by 512 PNG files; the COVID-19 images are JPGs gathered from many sources. A classifier that never sees a pixel, only the file type, gets every COVID-19 and tuberculosis test image right.

A ResNet-18 trained and tested with the centre 70% of every image blacked out, so it never sees the lungs, still reaches 84.6% and finds all 41 tuberculosis cases. On this set, much of the accuracy comes from where an image was taken, not from the disease.

Where the full model looks

The heat map is a class activation map: ResNet-18 ends in an average over a 5 by 5 grid of features followed by one linear layer, so the evidence for each answer can be read off that grid exactly. Red and yellow mark the regions that pushed the model toward its answer.

Over the 771 test images, about 56% of the evidence for the answer falls inside the central area that holds the lungs. That area is 49% of the image, so the model favours the lungs only slightly; a third to a half of its evidence comes from the borders, where the collections differ.

Making it small

Channel pruning removes whole filters, so the network actually gets cheaper; 8-bit quantization stores weights and activations as integers. Each pruned model was fine-tuned for three epochs, with and without distillation from the full model.

How it was done

ResNet-18 from ImageNet weights, 160 by 160 grayscale input, six epochs with light augmentation and class-weighted loss. Validation was a stratified 10% of the training images; the 771 test images were scored at the end. Pruning: L1-magnitude structured pruning with torch-pruning. Quantization: ONNX Runtime static int8, per-channel weights, 256 calibration images. All three models on this page are the 8-bit versions.

Built by Read Alalloş. Data: “Chest X-ray (Pneumonia, COVID-19, Tuberculosis)” on Kaggle, which combines the pediatric pneumonia set of Kermany et al. (2018), a tuberculosis database and COVID-19 collections. Not a medical device.
